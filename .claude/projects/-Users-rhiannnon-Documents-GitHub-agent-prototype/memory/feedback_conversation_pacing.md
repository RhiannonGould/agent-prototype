Having the user restate the experiment/plan in their own words at the end of a session works well — keep doing that.

**Why:** It confirms ownership and clarity. The user found this valuable in the Diane session.

**How to apply:** Always close boundary-setting with the user articulating the plan back. However, move toward plan-building earlier in the conversation — the Socratic exploration phase ran too long before transitioning to actionable design. Once the user's core concern and values are clear, start shaping the experiment sooner rather than continuing to probe.
